# Sinal Pro - Signal Generator

## Overview
A Portuguese-language predictive signal generator web application. This is a purely frontend application built with HTML, JavaScript, and Tailwind CSS.

## Project Structure
- `index.html` - Main HTML file with all markup and styling
- `app.js` - JavaScript module containing the SignalApp class with all application logic
- `slot-icon.png` - Icon asset for the UI
- `chip-background.png` - Background image asset
- `scan-hum.mp3` - Audio file for scanning effect
- `success-chime.mp3` - Audio file for success notification

## Technology Stack
- Vanilla JavaScript (ES6 modules)
- Tailwind CSS (CDN)
- HTML5 Web Audio API

## Running the Application
The application is served as static files using Python's built-in HTTP server on port 5000.

## Deployment
Configured for static deployment - all files in the root directory are served.
